# InterviewIQ

AI Interview & Career Copilot

## Overview

InterviewIQ is a full-stack AI platform designed to help candidates prepare for technical, behavioral, and HR interviews.

## Planned Features

- User authentication
- Resume upload and parsing
- Resume-aware RAG chatbot
- AI-generated mock interviews
- Answer evaluation and feedback
- Interview analytics
- Speech analysis
- Video interview analysis
- Personalized improvement recommendations
